# Réponses aux questions de réflexion

## Exercice 2.5 — Mini-projet d’intégration (CI/CD)

Pour transformer ce script en un véritable pipeline CI, j'ajouterais les étapes suivantes :

1. **Installation des dépendances** nécessaires au projet.
2. **Vérification du code** avec un outil d'analyse statique.
3. **Exécution des tests automatisés** pour vérifier le fonctionnement du programme.
4. **Compilation ou construction** de l'application si nécessaire.
5. **Création d'un artefact** contenant la version validée du projet.
6. **Déploiement automatique** sur un environnement de test, après la réussite des étapes précédentes.
